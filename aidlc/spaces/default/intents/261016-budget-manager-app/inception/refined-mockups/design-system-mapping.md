# デザインの決まりごと

既存のデザインシステムはありません（新規開発）。この表が、実装で使う色・文字・余白・部品の基準です。見本は `assets/refined-mockup.html` です。方向性は、ラフモックアップで依頼者が確認した「落ち着き・安心、ライトのみ、派手な色や動きなし」です（`aidlc/spaces/default/intents/261016-budget-manager-app/ideation/rough-mockups/wireframes.md`）。画面の構成は `aidlc/spaces/default/intents/261016-budget-manager-app/ideation/rough-mockups/user-flow.md` の情報構成に従います。

## 色

| 名前 | 値（OKLCH） | 用途 |
|------|-------------|------|
| ink | oklch(24% 0.02 220) | 本文の文字 |
| ink-2 | oklch(40% 0.02 220) | 補足の文字、見出しの小さい文字、プレースホルダー、枠線 |
| paper | oklch(98.5% 0.006 85) | 背景 |
| paper-2 | oklch(95.5% 0.008 85) | 確認の枠の背景 |
| line | oklch(80% 0.01 85) | 罫線 |
| accent | oklch(42% 0.07 200) | 主要ボタン、操作位置の枠線、ステップ名 |
| accent-soft | oklch(93% 0.025 200) | 成功のお知らせの背景、選んだ区分の背景 |
| warn | oklch(45% 0.12 40) | 誤り・超過の文字、誤りの欄の枠 |
| warn-soft | oklch(94% 0.03 40) | 警告のお知らせの背景 |

純粋な白と黒は使いません。色は1つのアクセント（藍緑）に絞ります。

## 文字

| 名前 | 大きさ | 用途 |
|------|--------|------|
| text-sm | 0.875rem（14px） | 補足、ラベル、表の列見出し |
| text-base | 1rem（16px） | 本文、入力欄 |
| text-lg | 1.25rem（20px） | 見出し（h2）、月名 |
| text-xl | 1.75rem（28px） | 収入・支出・差額の数値 |

- 書体は端末標準の日本語フォント（system-ui、Hiragino Sans、Yu Gothic UI）。外部フォントは読み込まない（外部通信なし）。
- 金額は等幅数字（tabular-nums）で右揃え。
- 単位は rem で指定し、ブラウザの文字サイズ設定に従う。

## 余白

4 の倍数の段階: 4 / 8 / 16 / 24 / 48px（space-xs〜space-xl）。

## 部品

| 部品 | 決まりごと |
|------|------------|
| 主要ボタン | accent の背景に paper の文字。1つの区切りに1つまで |
| 通常のボタン | paper の背景、ink-2 の枠 |
| ボタン共通 | 高さ 44px 以上。ラベルは「登録する」「予算を保存」など動詞＋対象にする（「OK」は使わない） |
| 入力欄 | 高さ 44px 以上、見える見出しを上に置く |
| お知らせ枠 | 成功は accent-soft、警告・誤りは warn-soft。見出し（太字）＋説明 |
| 確認の枠 | 操作したボタンのすぐ下。paper-2 の背景、2px の枠。選択肢のボタンを横に並べる |
| 表 | 罫線は横線のみ。金額の列は右揃え |
| 操作位置の枠線 | 3px、accent、外側に 2px 離す（:focus-visible） |

## 動き

- 動きは状態の変化を示す最小限に留め、時間は 300 ミリ秒以内とする。
- 依頼者が「派手な動きを避ける」と決めているため、ページ表示時の演出は付けない。
- 利用者の端末で「視差効果を減らす」が有効なときは、動きをすべて止める（prefers-reduced-motion）。

## 画面幅

| 幅 | 振る舞い |
|------|----------|
| 1024px 以上 | 主な対象。内容の幅は最大 860px で中央寄せ |
| 768〜1023px | 2列の部分（日付と金額、収入・支出・差額）を1列にする |
| 768px 未満 | 対象外（崩れても許容） |
