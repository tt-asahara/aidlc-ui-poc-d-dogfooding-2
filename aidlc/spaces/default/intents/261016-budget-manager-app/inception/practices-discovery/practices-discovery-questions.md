## Q8. 書式チェックを、`main` に取り込む前にどこで必ず実行しますか？

Q6 では「Prettier と ESLint を自分のパソコンで実行する」を選んでいただきました。一方、このワークスペースの共通ルール（`org.md` の Code Style）では、リンターは取り込み前に CI（GitHub 上での自動実行）で実行し、失敗したら取り込みを止める、と定めています。このままでは共通ルールと食い違うため、どちらに合わせるかを決めてください。

A. 普段はパソコンで実行し、`main` へ取り込む前には GitHub Actions でも自動実行して、失敗したら取り込まない（共通ルールに合わせる。CI の用意は後の段階で行う）
B. Q6 を変更し、最初から GitHub Actions で push のたびに自動実行する
C. パソコンでの実行のみとし、共通ルールとは食い違ったままにする（このプロジェクトのルールとして記録できない可能性がある）
D. 特に希望はない（おすすめでよい）
