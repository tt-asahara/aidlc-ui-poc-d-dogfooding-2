# 外部の依存

Bolt とは、作業の一部を設計から実装・テストまで1回通し、ブラウザで動くものができたところで区切る単位です（計画は `bolt-plan.md`）。

このアプリは架空のデータだけを使います。実口座との連携も外部への送信もありません（依頼文、要件 NFR3）。そのため、外部の API・データ・承認待ち・ほかのチームからの引き渡しで作業が止まるものはありません（Q5）。

## 作業に使う外部のもの

どれも作業を止めるものではありません。

| もの | 持ち主 | 使う Bolt | かかる時間 | 使えないとき |
|------|--------|-----------|------------|--------------|
| GitHub（`origin`、作業ブランチ `feat/budget-manager-app` への push） | 依頼者のリポジトリ（GitHub） | 全 Bolt（各区切りのコミットと push） | 待ち時間なし | 手元でコミットして作業を続け、使えるようになったら push する。push できなかったことは、その区切りの報告に書く |
| npm の部品（TypeScript、Vitest、Playwright、Prettier、ESLint、画面の組み立てに使う部品など） | npm の公開レジストリ | B1（最初の取得）、以降は必要に応じて | 最初の取得で数分 | 取得できるまで、取得済みの範囲で作業を続ける。部品の追加は、取得できるようになってから行う |
| Playwright のブラウザ本体 | Playwright（Microsoft）の配布元 | B1（最初の取得）、B6 | 最初の取得で数分 | 取得できるまで、単体テストで作業を続ける。ブラウザ操作のテストは取得後にまとめて実行する |
| GitHub Actions（`main` への取り込み前の Prettier・ESLint） | GitHub | B6 のあと（`main` への取り込みの前） | 1回数分 | 手元で同じ確認を通したうえで、取り込みは Actions が通るまで待つ |

## 外部に出さないもの

- 秘密情報、個人情報、`node_modules` はコミットしません（team-practices.md、`.gitignore`）。
- アプリは外部へ通信しません。外部のフォント・スクリプト・解析ツールも読み込みません（要件 NFR3）。npm の部品は、開発とテストのときにだけ使います。
