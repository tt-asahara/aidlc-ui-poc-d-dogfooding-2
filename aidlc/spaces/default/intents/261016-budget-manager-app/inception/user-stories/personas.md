# ペルソナ

## P1 家計を試す本人（依頼者）

| 項目 | 内容 |
|------|------|
| 役割 | このアプリのただ1人の利用者。依頼者・判断者も兼ねる |
| 目標 | 自分の収支と月ごとの予算の状況を把握・管理する手段を、架空データで安全に試す。登録 → 月次集計を確認 → CSV に出力を、手順書なしで迷わずに行う |
| 困りごと | 実データを使わずに家計管理アプリの使い勝手を確かめたい。表計算での手作業に代わる形を試したい |
| 利用環境 | 自分のパソコンのブラウザ（PC 中心、ライトテーマ）。データはそのブラウザ内に保持する |
| 機器への慣れ | 中〜高（CSV や表計算ソフトを扱える） |
| 利用頻度 | 試作の確認中に、数日〜数週間、繰り返し使う |
| アクセシビリティ | WCAG 2.1 AA 相当。キーボードだけでも操作できること |

出典: 意図ステートメント（利用者・目的・成功基準）、ラフモックアップの回答（PC 中心・ライト・WCAG 2.1 AA）、`requirements.md`。

## ペルソナどうしの関係と優先度

ペルソナは P1 だけです。依頼者以外の利用者・関係者はいないと確認済みです（意図の把握 Q2、Q5）。すべてのストーリーは P1 のものです。
