## 登録フォーム（EntryForm）

| 項目 | 内容 |
|---|---|
| 部品 | EntryForm |
| 説明 | 収入・支出の明細を1件登録する |
| 種類 | input |

### 状態

| 状態 | 説明 | きっかけ |
|---|---|---|
| default | 区分「支出」、日付は今日、他は空 | 表示時・登録成功後 |
| focus | 操作中の欄に 3px の枠線 | Tab キー・クリック |
| error | 誤りのある欄の枠が太くなり、欄の下に理由と例を表示。入力値は残る | 「登録する」で検証に失敗（AC1.2.1、AC1.2.3） |
| success | フォーム上のお知らせ枠に「登録しました 日付 カテゴリ 金額」 | 登録成功（AC1.1.1） |
| other-month | お知らせ枠に「N月の明細として登録しました 日付 カテゴリ 金額」、表示月を切り替え | 表示中と別の月の日付で登録（AC1.3.1） |
| storage-error | お知らせ枠に保存失敗と再試行の方法。入力値は残る | 保存に失敗（AC7.3.1） |
| disabled | 「登録する」が押せず、理由を表示 | 保存データが壊れている（AC7.3.3） |

### 入力項目

| 項目 | 種類 | 必須 | 規則 |
|---|---|---|---|
| 区分 | 2択（支出・収入） | はい | 切り替えると合わないカテゴリの選択を解除（AC1.1.3） |
| 日付 | 日付 | はい | 存在する日付。範囲の制限なし |
| 金額（円） | 文字（数字キーボード） | はい | 半角の 1〜9,999,999 の整数。前後の空白は除く |
| カテゴリ | 選択 | はい | 区分に合う固定カテゴリのみ |
| メモ | 文字 | いいえ | 前後の空白を除いた後で 100 文字まで（見える1文字を1文字）。改行不可。101 文字目は入力できない |

### 動き

- 検証は「登録する」を押したときに行う。最初の誤りの欄へ操作位置を移す。
- 登録中は「登録する」を押せなくし、300 ミリ秒以内の2回目の操作で明細が増えないようにする（AC1.1.4）。
- 成功したら、区分と日付を残し、金額・メモを空にして金額欄へ操作位置を移す（続けて入力しやすくするため）。
- メモは常に文字として表示し、書式として解釈しない（AC1.1.5）。

### 画面幅

| 幅 | 振る舞い |
|---|---|
| 768px 未満 | 対象外 |
| 768〜1023px | 日付と金額を1列に縦並び |
| 1024px 以上 | 日付と金額を2列 |

### アクセシビリティ

| 要件 | 実装 |
|---|---|
| 役割 | form。区分は fieldset と legend、ラジオボタン |
| キーボード | Tab で項目を移動。区分は矢印キー。Enter で登録 |
| 見出し | 各欄に見える見出し（label）を付ける。プレースホルダーだけにしない |
| コントラスト | 本文 4.5:1 以上（`accessibility-checklist.md`） |
| 読み上げ | 誤りは aria-invalid と aria-describedby で欄と結び付ける。成功・失敗のお知らせは aria-live（成功は polite、失敗は alert）で読み上げる |
| 操作位置 | 失敗時は最初の誤りの欄、成功時は金額欄 |

## 月の切り替え（MonthNav）

| 項目 | 内容 |
|---|---|
| 部品 | MonthNav |
| 説明 | 表示する月を前後に切り替える。集計と明細一覧が同時に変わる |
| 種類 | navigation |

- 開いたときは今日を含む月（AC3.1.4）。「前の月」「次の月」で1か月ずつ移動し、年をまたぐ（AC3.1.3）。
- 月名は aria-live="polite" で読み上げる。ボタンは「前の月」「次の月」の文字を表示する（記号だけにしない）。

## 月次集計の表と予算入力（MonthlySummary / BudgetTable）

| 項目 | 内容 |
|---|---|
| 部品 | MonthlySummary、BudgetTable |
| 説明 | 収入・支出・差額と、支出カテゴリ別の予算（入力欄）・実績・残額を表示する |
| 種類 | display / input |

### 状態

| 状態 | 説明 | きっかけ |
|---|---|---|
| populated | 値を表示 | 通常 |
| negative | 差額に「−」 | 支出が収入を超える（AC3.1.2） |
| over-budget | 残額欄に「超過 ¥N」を文字と色で表示 | 実績 > 予算（AC3.2.2） |
| unset | 予算欄が空（プレースホルダー「未設定」）、残額「—」、案内文 | 予算未設定（AC3.2.3） |
| editing | 予算欄に入力中 | 入力 |
| error | 誤りのある予算欄の下に理由。入力値は残る | 保存時の検証失敗（AC4.1.2） |
| copy-confirm | ボタンの下に上書き確認の枠（「上書きする」「やめる」） | 写し先に予算がある状態でコピー（AC4.2.2） |
| copy-empty | 「前の月の予算がありません」 | 前の月に予算がない（AC4.2.3） |
| disabled | 入力欄とボタンが操作できない | 保存データが壊れている（AC7.3.3） |

### 動き

- 予算欄は半角の 0〜9,999,999 の整数。空欄は「未設定」。「予算を保存」で、その月の全欄をまとめて検証・保存する。1つでも誤りがあれば何も保存しない。
- 実績の合計は支出合計と一致させる（AC3.1.5）。金額は円の整数で計算する（AC3.1.6）。
- 「前の月の予算をコピー」: 前の月に予算がなければ copy-empty。写し先に予算が1つでもあれば copy-confirm。なければすぐ写す。確認の枠は「やめる」と Escape キーで閉じ、閉じたらコピーのボタンへ操作位置を戻す。
- 収入カテゴリは表に出さない（予算は支出のみ）。

### アクセシビリティ

| 要件 | 実装 |
|---|---|
| 表 | table、caption、列見出しは th scope="col"、行見出しは th scope="row" |
| 予算欄 | 各欄に「食費の予算（円）」のような名前を付ける |
| 超過 | 色に加えて「超過」の文字 |
| 確認の枠 | role="group" と見出しで名前を付け、表示時に最初の選択肢へ操作位置を移す |

## 明細の一覧（Ledger）

| 項目 | 内容 |
|---|---|
| 部品 | Ledger |
| 説明 | 表示中の月の明細を新しい順に表示する |
| 種類 | display |

- 並び順: 日付の新しい順。同じ日付は後から追加したものを上（CSV の取り込みでは、ファイルの下の行ほど上）（AC2.1.1、AC2.1.2）。
- 列: 日付（MM/DD）、区分、カテゴリ、金額（支出は「−」、収入は「+」、¥と3桁区切り、右揃え、等幅数字）、メモ（AC2.1.3）。
- 明細がないときは表を出さず、案内文を表示する（AC2.1.4）。
- 1か月約 100 件までを想定し、ページ分けはしない。

## CSV の出力・取り込み（CsvPanel）

| 項目 | 内容 |
|---|---|
| 部品 | CsvPanel |
| 説明 | すべての明細の CSV 保存と、CSV からの追加 |
| 種類 | input / feedback |

### 状態

| 状態 | 説明 | きっかけ |
|---|---|---|
| default | 説明文（追加のみ、予算は含まれない、形式）とボタン | 通常（AC5.1.5） |
| export-empty | 「出力する明細がありません」 | 明細 0 件で保存（AC5.1.4） |
| duplicate-confirm | ボタンの下に「既存と同じ明細が N 件あります」と3つの選択肢 | 重複がある取り込み（AC6.3.1） |
| import-success | 追加件数・取り込めなかった件数・重複として除いた件数 | 取り込み完了（AC6.1.1、AC6.1.7） |
| import-partial-error | 追加件数と、取り込めなかった行番号・理由の一覧 | 一部の行が不正（AC6.2.1） |
| import-file-rejected | ファイル全体を取り込めない理由。何も追加しない | 見出し違い・UTF-8 以外・閉じていない引用符・空・大きすぎる（AC6.1.3〜AC6.1.5、AC6.2.6） |
| disabled | 取り込みを操作できない | 保存データが壊れている（AC7.3.3） |

### 取り込みの検証規則（行単位で取り込まない）

- 列の数が 5 でない
- 日付が YYYY-MM-DD でない、または存在しない日付
- 区分が「収入」「支出」でない
- カテゴリが用意されていない、または区分と合わない
- 金額が半角数字でない、または 1〜9,999,999 の範囲外
- メモが 100 文字を超える、または改行を含む（Q2）
- 値の前後の空白は、検証の前に除く（メモも含む。Q3）
- 空行は無視して件数に数えない

### 動き

- 取り込みは、ファイル全体の確認 → 行ごとの検証 → 重複の確認 → 追加、の順。追加はすべてまとめて保存し、失敗したら取り込み前の状態に戻す（AC6.1.6）。
- 重複の確認の「取り込みをやめる」と Escape キーでは何も追加しない。
- 出力のファイル名は `budget-entries-YYYYMMDD.csv`。数式対策: 先頭が = + - @ ' タブ 改行のメモは、先頭に「'」を1つ付けて出力し、取り込み時に先頭の「'」を1つ外す（AC5.2.1、AC5.2.2）。

## 全体のお知らせ枠（AppBanner）

| 状態 | 表示 | きっかけ |
|---|---|---|
| storage-corrupt | 「保存データを読み込めませんでした。データは消していません。」と、止めている操作の説明（role="alert"） | 起動時に保存データを読めない（AC7.3.3、AC7.3.4） |
| other-tab-changed | 「別のタブで変更がありました。最新の内容を読み込みました」（role="status"） | 別のタブで保存された（AC7.4.1） |
