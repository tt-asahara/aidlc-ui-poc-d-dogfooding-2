# ラフワイヤーフレーム — 架空データの予算管理Webアプリ

## 前提と入力

- 意図ステートメント（`aidlc/spaces/default/intents/261016-budget-manager-app/ideation/intent-capture/intent-statement.md`）: 依頼者本人が1人で、架空データを使って家計（収支と予算）の管理を試す。成功基準は「登録 → 月次集計を確認 → CSV に出力」を迷わず完了できること。
- 範囲定義書（`aidlc/spaces/default/intents/261016-budget-manager-app/ideation/scope-definition/scope-document.md`）: 登録と一覧（修正・削除なし）、用意済みカテゴリ、月ごとのカテゴリ別予算、月次集計（収入・支出・差額と予算・実績・残額）、明細 CSV の出力と追加取り込み、サンプルデータ同梱、ブラウザ内での保持。
- 意図バックログ（`aidlc/spaces/default/intents/261016-budget-manager-app/ideation/scope-definition/intent-backlog.md`）: PU-1 登録と一覧 → PU-2 月次集計 → PU-3 CSV 出力 → PU-4 予算と予算比較 → PU-5 CSV 取り込み（価値優先の順）。
- このステージの回答（`rough-mockups-questions.md`）: パソコン中心、落ち着いて安心できる印象、ライトのみ、最初に登録フォーム、WCAG 2.1 AA 相当、派手な色や動きは避ける。

## 見た目の方向（Visual Direction）

- 落ち着きと安心: 深い藍緑を唯一のアクセント色とし、他は温かみをわずかに帯びた紙のような中間色でまとめる。純粋な白黒は使わない。
- 数字の読みやすさ: 金額は等幅数字で右揃えにし、3桁区切りと「¥」を付ける。
- 派手さを避ける: グラデーション、影の強いカード、装飾的なアニメーションは使わない。カードを入れ子にせず、余白と罫線で区切る。
- 文字: 端末標準の日本語フォントを使う（外部フォントを読み込まない）。本文は 16px 以上。
- 色だけに頼らない: 予算超過は色に加えて「超過 ¥3,900」と文字で示す。入力エラーは枠線に加えて説明文を出す。

## ラフ案A: 縦積みのステップ順

成功基準の流れ「1 登録 → 2 確認 → 3 書き出し」をそのまま上から下へ並べる、1列の構成です。

```
+--------------------------------------------------------------+
| 予算管理   架空データで試す家計簿                            |
+--------------------------------------------------------------+
| 1 登録                                                       |
|  収支を登録                                                  |
|  [ 支出 | 収入 ]                                             |
|  日付 [2026-10-14]        金額（円） [ 例: 1280 ]            |
|  カテゴリ [ 食費 v ]                                         |
|  メモ（任意） [ 例: スーパー ]                               |
|  [ 登録する ]                                                |
+--------------------------------------------------------------+
| 2 確認                                                       |
|  月次集計   < 2026年10月 >                                   |
|  収入 ¥280,000   支出 ¥119,220   差額 ¥160,780               |
|  カテゴリ | 予算 | 実績 | 残額                               |
|  食費     | ...  | ...  | ...                                |
|  [ 10月の予算を設定 ]                                        |
|  10月の明細（新しい順）                                      |
|  日付 | 区分 | カテゴリ | 金額 | メモ                        |
+--------------------------------------------------------------+
| 3 書き出し                                                   |
|  CSV   [ 明細を CSV に保存 ] [ CSV を取り込んで追加 ]        |
+--------------------------------------------------------------+
```

- アクセシビリティ: h1「予算管理」、各ステップは h2。ランドマークは header / main。キーボードの入口は「本文へ移動」リンク、続いて区分の切り替え。

## ラフ案B: タブ切替

「登録」「明細」「月次集計・予算」「CSV」をタブで切り替えます。開いた直後は「登録」タブで、フォームだけが大きく見えます。

```
+--------------------------------------------------------------+
| 予算管理   架空データで試す家計簿                            |
+--------------------------------------------------------------+
| [登録] [明細] [月次集計・予算] [CSV]                         |
| ------                                                       |
|  収支を登録                                                  |
|  [ 支出 | 収入 ]                                             |
|  日付 [2026-10-14]   金額（円） [     ]                      |
|  カテゴリ [ 食費 v ]                                         |
|  メモ（任意） [     ]                                        |
|  [ 登録する ]                                                |
+--------------------------------------------------------------+
```

- アクセシビリティ: h1「予算管理」、タブパネル内の見出しは h2。ランドマークは header / main。タブは左右の矢印キーで移動し、Tab キーでパネルへ入る。

## ラフ案C: 入力を常設した帳簿

左側に入力フォームと CSV 操作を常に表示し、右側にその月の集計と明細を帳簿のように並べます。登録した結果が、すぐ右に反映されて見えます。

```
+--------------------------------------------------------------+
| 予算管理   架空データで試す家計簿                            |
+--------------------+-----------------------------------------+
| 収支を登録         | 月次集計   < 2026年10月 >               |
| [ 支出 | 収入 ]    | 収入 ¥280,000  支出 ¥119,220  差額 ...  |
| 日付 [         ]   | カテゴリ | 予算 | 実績 | 残額           |
| 金額（円） [   ]   | ...                                     |
| カテゴリ [   v ]   | [ 10月の予算を設定 ]                    |
| メモ [         ]   |                                         |
| [ 登録する ]       | 10月の明細                              |
|--------------------| 日付 | 区分 | カテゴリ | 金額 | メモ    |
| CSV                | ...                                     |
| [保存] [取り込み]  |                                         |
+--------------------+-----------------------------------------+
```

- アクセシビリティ: h1「予算管理」、左右それぞれの見出しは h2。ランドマークは header / aside（入力）/ main（集計と明細）。キーボードの入口は「本文へ移動」リンク、続いて左側フォームの先頭。

## 画面の状態

3案とも、同じ状態を表示できます。HTML 下部の切り替えバーの「状態」で選べます。

| 状態 | 見え方 | 次にできること |
|------|--------|----------------|
| 通常（サンプルデータあり） | 架空の明細7件と予算が入った10月を表示 | 登録、月の切り替え、CSV 操作 |
| 入力に誤りがある | 金額欄の枠が太くなり、下に「金額は1以上の整数で入力してください。例: 1280」と表示。入力した内容は残る | 金額を直して再度「登録する」 |
| 登録できた | フォーム上部に「登録しました」と何を追加したかを表示 | 続けて登録、集計を確認 |
| その月の明細がない | 一覧の代わりに、登録か CSV 取り込みを案内する文 | 登録する、CSV を取り込む |
| 予算が未設定 | 予算と残額の欄に「未設定」「—」を表示し、設定を案内 | 「10月の予算を設定」 |
| 予算を超えたカテゴリがある | 残額欄に「超過 ¥3,900」を文字と色で表示 | 明細を確認する |
| CSV を取り込めた | 「12件の明細を追加しました」と、既存の明細が残ることを表示 | 一覧で確認 |
| 一部の行を取り込めない | 追加できた件数と、取り込めなかった行番号と理由を表示 | CSV を直して取り込み直す |
| 保存先に書き込めない | 保存できなかったこと、入力は画面に残っていること、再試行の方法を表示 | 確認して再度「登録する」 |

読み込み中の状態は設けていません。データはこの端末のブラウザ内にだけあり、通信を伴わないためです。

## 試作の扱い

- `assets/rough-variants.html` は比較用の使い捨ての試作で、保存や取り込みは実際には行いません。`?variant=A|B|C` と `?state=<状態>` で切り替えられます。
- どの案を採用するか（または組み合わせるか）は、要件分析以降で決めます。この段階では決めません。

## 未確認の点

- 試作は、ブラウザでの表示とキーボード操作をまだ確認していません（作成時にブラウザの自動操作が使えなかったため）。構文チェックと、外部への通信がないことは確認済みです。
- 明細が多いとき（数百件）の一覧の見せ方は、要件分析で件数の目安を決めてから検討します。
