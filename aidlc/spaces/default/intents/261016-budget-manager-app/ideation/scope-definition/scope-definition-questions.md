# 範囲の定義 — 質問

前のステージで確認した内容（`aidlc/spaces/default/intents/261016-budget-manager-app/ideation/intent-capture/intent-statement.md`）を前提にしています。

- 必要な機能は「収支登録」「カテゴリ別予算」「月次集計」「CSV入出力」の4つで、架空データのみを扱います。
- 利用者は依頼者ご本人1人です。成功基準は「登録 → 月次集計を確認 → CSV 出力」を迷わず完了できることです。

ここでは、4つの機能それぞれを最初のバージョンでどこまで作るか、どの順で作るかを決めます。
