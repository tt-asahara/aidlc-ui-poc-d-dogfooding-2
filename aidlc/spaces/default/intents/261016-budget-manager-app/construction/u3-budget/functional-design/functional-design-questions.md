# 機能設計（U3 月別予算と予算比較）— 質問

U3（`aidlc/spaces/default/intents/261016-budget-manager-app/inception/units-generation/unit-of-work.md`）は、月次集計の表に予算の入力欄を足し、予算の保存、前の月の予算のコピー、予算比較（予算・実績・残額・超過・未設定）を作ります。受け持つストーリーは次の3つです。

- US3.2 カテゴリ別に予算と実績を比べる
- US4.1 月の予算を入力する
- US4.2 前の月の予算をコピーする

約束ごと C4（Budget）・C5（MonthlySummary）と U1 の予算の差し込み口を使います。予算の保存の失敗の表示（AC7.3.2 の予算の部分）も U3 が作ります。

ストーリーの受け入れ条件、詳細モックアップ（`inception/refined-mockups/interaction-spec.md` の「月次集計の表と予算入力」）、約束ごとで、多くのことは決まっています。どの質問も A がおすすめです。

すでに決まっていて、質問しないこと:

- **予算の値:** 0〜9,999,999 の整数で、空欄は「未設定」。1か月分をまとめて検証し、1つでも誤りがあれば何も保存しない。誤りの文は「予算は 0〜9,999,999 の整数で入力してください」（AC4.1.1〜AC4.1.3）。
- **表示:**
  - 残額 = 予算 − 実績。
  - 超過は「超過 ¥3,900」の文字と色で示す。
  - 未設定は、予算欄が空（プレースホルダー「未設定」）、残額は「—」で、超過にしない。
  - 収入カテゴリは表に出さない（AC3.2.1〜AC3.2.4）。
- **前の月の予算のコピー（AC4.2.1〜AC4.2.3）:**
  - 前の月に予算がなければ「前の月の予算がありません」と出す。
  - 写し先に予算があれば「10月の予算を前の月の内容で上書きします」と確認の枠を出し、「上書きする」「やめる」を選ばせる。
  - 確認の枠は Escape でも閉じる。
- **保存の失敗:** 予算の区切りのお知らせ枠に、登録と同じ形で出す。保存データが読めないときは、予算の保存とコピーを押せない状態にする（契約設計 Q4）。

## Q1. 「前の月の予算をコピー」で上書きするとき、前の月で未設定だったカテゴリはどうしますか？

例: 前の月は食費だけ設定、今月は食費と娯楽を設定済み。

A. 今月の予算を、前の月の内容でまるごと置き換える。前の月で未設定のカテゴリ（例の娯楽）は、今月も未設定になる（おすすめ。確認の文「前の月の内容で上書きします」のとおりで、結果が前の月と同じになり分かりやすい）
B. 前の月に設定のあるカテゴリだけを上書きし、それ以外のカテゴリ（例の娯楽）は今月の値を残す

## Consolidated Summary Confirmation

- 予算の入力と保存（AC4.1.1〜AC4.1.3）: 月次集計の表の支出カテゴリ8つの行に予算欄を置き、「予算を保存」で1か月分をまとめて検証して保存する。0〜9,999,999 の整数、空欄は未設定。1つでも誤りがあれば何も保存せず、その欄の下に「予算は 0〜9,999,999 の整数で入力してください」を出し、入力は残す。ほかの月の予算は変わらない
- 予算比較（AC3.2.1〜AC3.2.4）: 予算・実績・残額（予算 − 実績）を出す。実績が予算を超えたら残額に「超過 ¥N」を文字と色で出す。未設定は予算欄が空（「未設定」）で残額は「—」、超過にしない。収入カテゴリは表に出さない。U1 の予算の差し込み口を、本物の Budget に差し替える
- 前の月の予算のコピー（AC4.2.1〜AC4.2.3）: 前の月に予算がなければ「前の月の予算がありません」。写し先に予算があれば、ボタンの下に確認の枠（「10月の予算を前の月の内容で上書きします」、「上書きする」「やめる」、Escape で閉じる）。上書きは今月の予算を前の月の内容でまるごと置き換える（Q1。前の月で未設定のカテゴリは今月も未設定）。写し先に予算がなければ、すぐ写す
- 未保存の入力（Q2）: 月を切り替えたら、確認せずに入力を捨てて、その月の予算を表示する。予算欄の上に「「予算を保存」を押すまで、予算は保存されません」と1行書く
- 別のタブの変更: 確認の枠が開いていたら閉じ、予算の区切りのお知らせ枠に「別のタブで変更があったため、確認を取り消しました。もう一度操作してください」と出す（約束ごとの未解決の点 C6）。入力中の予算欄は、最新の予算で置き換える
- 保存の失敗（AC7.3.2 の予算の部分）: 予算の区切りのお知らせ枠に、登録と同じ形で出す（保存できない、別のタブが先に保存していた）。保存データが読めないときは、予算の保存とコピーを押せない状態にして理由を出す
- U3 で作らないもの: 取り込み（U4）、通しのアクセシビリティの確認（U6）
